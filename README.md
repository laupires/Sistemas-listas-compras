# Sistema de Lista de Compras

Projeto final da disciplina de Sistemas Web I.

O sistema permite cadastrar, listar, editar, excluir e marcar itens de uma lista de compras como comprados.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- JSON

## Como executar

Entre na pasta backend:

```bash
cd backend
npm install
node server.js
```

Depois, com o backend rodando, abra o arquivo `index.html` da pasta `frontend` usando o Live Server.
